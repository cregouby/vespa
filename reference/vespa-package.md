# vespa: Mesh Transformations Using 'Vespa' 'VTK/CGAL' Mesh Processing Library

Provides R wrappers for all 'Vespa' 3D mesh filters (isotropic
re-meshing, boolean operations, alpha wrapping, surface reconstruction,
point set processing, as-rigid-as-possible deformation and more) via
direct 'Rcpp' bindings to the 'Vespa C++' 'VTK/CGAL' library. Also
includes a very fast 'STL' and 'VTP' file reader.
