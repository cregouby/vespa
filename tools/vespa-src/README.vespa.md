# Vendored Vespa sources

This directory contains a vendored copy of the Vespa C++ library used by the
`vespa` R package.

- Upstream: <https://gitlab.kitware.com/vtk/meshing/vespa>
- Commit: `a20e7c46470984abebb6837b9946a9ebb517452d`
- License: BSD-3-Clause, see `License.txt`
- Included: the library sources under `vespa/`, the top-level CMake files,
  and the license/readme files.
- Excluded: upstream data, ParaView plugin, tests, and CI configuration.

The `module-headers/` directory contains minimal replacements for the export
headers normally generated by VTK's `vtk_module_build`. The package compiles
these sources directly, so the export macros are defined as empty by
`configure` and `configure.win`.
